## Independent comparison evidence

The [recorded run](../static/experiments/orm-comparison-2026-10-01.json) preserves the actual compiler/runtime output for the eight stable library projects. It includes exact installed versions, project and lock hashes, the runner and article hashes, image digests and verified container cleanup. All three compiler versions passed the expected-error checks and rejected the unsuppressed negatives at their intended statements. Runtime controls reproduced missing/omitted fields, unloaded relations, database/validation failures and Mongoose's silently empty misspelled filter. This is a new reproduction, not the missing original experiment. Preview and TypedSQL claims are outside its scope and no longer contribute to the published grades.

The comparison uses MikroORM 7.2.3 after the registry recheck found that patch. Prisma's moving `latest` tag pointed to an 8.0.0 release candidate at that check, so stable 7.10.0 remains an explicit pin. Nine publisher-registry sources were added to the lifecycle mappings; a tag is a review trigger and can point to a preview. Neither fingerprints nor new releases automatically update pins or article dates.
